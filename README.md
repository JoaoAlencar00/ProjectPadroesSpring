# Projeto Padrões de Projeto Java

## Padrões utilizados

- **Singleton:** PedidoManager garante uma única instância do gerenciador de pedidos.
- **Factory Method:** PedidoFactory cria diferentes tipos de pedidos sem expor a lógica de instância.
- **Strategy:** Diferentes estratégias de desconto (NoDiscount e TenPercentDiscount) aplicadas dinamicamente.

## Como executar

1. Abra a IDE e importe o projeto como Java Project.
2. Execute a classe `Main.java`.
3. Observe os pedidos criados e os valores com desconto aplicados.
